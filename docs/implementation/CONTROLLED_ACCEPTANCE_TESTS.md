# Controlled Evaluation Acceptance Tests

The adjacent `controlled-evaluation-eligibility.test.ts` exercises the server
eligibility helper with reports generated by `runControlledEvaluation`. The
target invocation and evidence resolver are deterministic in-memory stubs; the
tests do not contact a provider, database, or external service. The positive
case also checks that the generated complete report passes
`isControlledEvaluationReportIntact` before the eligibility helper accepts it.

## Coverage

The suite contains **14 tests**. It covers acceptance of complete prompt-bound
evidence and rejection of changed candidate text or hash, changed baseline
text, stored configuration mismatch, detached context or source-version
evidence, a missing pair, a failed target call, invalid or failed verification,
wrong run or attempt binding, and lexical fallback represented as GraphRAG.

Run it with:

```sh
rtk corepack pnpm exec vitest run --config vitest.config.ts 'apps/web/src/app/api/projects/[projectId]/experiments/[experimentId]/decision/controlled-evaluation-eligibility.test.ts'
```

Latest focused result: **1 test file passed; 14 tests passed**. File lint,
formatting, and a strict TypeScript compile of the test and its imports also
passed.

## Limits

These tests call the server eligibility helper directly. They do not exercise
HTTP routing, database persistence, real provider calls, or live retrieval.
GraphRAG source and context evidence is deterministic fixture data; the report
still goes through the existing evaluator and full report integrity checks.
