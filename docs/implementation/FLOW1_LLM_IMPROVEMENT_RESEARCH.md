## Apa yang sudah didukung dan apa yang masih hipotesis

- **Didukung oleh source dan run final:** kandidat setelah revisi terakhir diuji pada kedua kasus; manifest lengkap dan intact mengikat prompt, konfigurasi, input, request, response, serta hash jawaban; verifier math cocok dengan oracle; semua fixture coding dieksekusi di sandbox; campaign mencatat reservation sebelum request.
- **Masih belum terbukti:** uplift rata-rata pada prompt lain, dampak perubahan effort, dan bukti formal kompleksitas. Verifier menyatakan limitation kompleksitas secara eksplisit.
- **Hipotesis yang tidak boleh ditulis sebagai hasil:** effort lebih tinggi memperbaiki matematika, loop Self-Refine meningkatkan kualitas pada PromptLab, reasoning/action loop generik meningkatkan akurasi, atau fixture perilaku membuktikan kompleksitas waktu/memori.

## Batas kesimpulan saat ini

- Artefak historis `57bb…`, `75d…`, dan recovery `600308…` tetap menunjukkan percobaan lama yang tidak cukup untuk lulus Flow 1. Run final memberi bukti baru: baseline salah (`sum=170995`), kandidat akhir benar (`sum=200995`) pada satu input yang ditetapkan. Ini bukan eksperimen statistik atau bukti uplift umum.
- Varian pada artefak paired memakai model dan effort yang sama. Belum ada perbandingan antar-effort, jadi tidak ada dasar untuk menyebut effort sebagai penyebab atau perbaikan.
- Kandidat revisi terakhir diuji dan hash draft cocok dengan manifest. Run melewati persisted web run endpoint dan worker, tetapi tidak menggantikan acceptance browser seluruh produk atau membuktikan full provider-backed user journey.
- Tes offline agent mengonfirmasi kontrak evaluasi dan invalidasi; catatan awal menyebut 33 tes terarah, sedangkan rerun independen terbaru lulus 42/42 pada lima file tes Flow 1. Typecheck agent dan worker juga lulus pada rerun. Bukti ini berlaku untuk file tes tersebut dan dua kasus Flow 1, bukan jaminan uplift umum.
- Kompleksitas coding tidak disertifikasi verifier otomatis. Tinjauan struktur kode final melihat dua loop atas `n × n`, list DP satu dimensi, dan tidak ada salinan `blocked`; hasil fixture bukan bukti kompleksitas formal.
- Jadwal read-only/shutdown Evals dan hasil empat paper adalah sumber eksternal yang diverifikasi pada tanggal audit; keduanya tidak menjadi bukti hasil PromptLab dan dapat berubah pada sumber masing-masing.
